# City Frames

The city is a field of small, remembered frames. Its visual language alternates between a quiet, continuous surface and precise rectangular interruptions. The composition should be meticulously spaced: generous geography, compact controls, and images that carry recognition before text explains it.

Harbour green anchors the system; pale mineral surfaces leave room for colourful film posters. Terracotta belongs to the visitor's own route. Colour has a job: distinguish the shared catalogue from the personal journey. Repeated calibration of these relationships matters more than adding ornament.

A restrained editorial serif names the place and the project. A clear sans serif handles actions, search and records. The typography rewards close attention without competing with the film imagery. Careful optical alignment, consistent image crops and deliberate line lengths are the craft of this system.

The conceptual thread is a filmstrip becoming geography. Frames gather, separate and connect across space. A small sequence of numbered stops suggests movement, while an open field preserves the possibility of a different journey. The accompanying canvas uses real catalogue coordinates as an abstract spatial composition; it is not a basemap or a navigation diagram.

## Web application

- Map / Diagram structure; existing Newsreader + IBM Plex Sans typography.
- Floating film catalogue, poster location markers, contextual detail and itinerary panels.
- English first; Chinese switch. All actions work without a backend account.
- Shared catalogue: search and filters. Personal content: editable itinerary and place notes, stored locally with notes export/import.
- Course provenance: the assessed project is Android; this is a later Web update.
- Reference: Anitabi's map-first browsing and linked selection, adapted to this film catalogue. No source code or visual assets copied from Anitabi.

Desktop: catalogue | large map | selected detail (or itinerary). Mobile: map above a compact bottom catalogue; detail opens over the map.
