Film → scene → place

电影 → 场景 → 地点

A film can have several scenes; a place can appear in several films. Keeping those records separate lets a visitor discover a place through a movie while adding the place only once to an itinerary.

一部电影可以关联多个场景，一个地点也可以出现在多部电影中。把三类记录分开，既能通过电影寻找地点，也能避免同一个地点重复加入行程。

Design decisions

设计与实现

Keep geography in view

让地图始终在视野里

On a desktop, a floating catalogue sits over the map; details and itineraries open on demand. Film selection narrows the visible places; place selection brings up its scene records. Screen-space clusters keep dense neighbourhoods readable.

桌面布局以地图为底，电影目录悬浮在左侧，详情和行程按需展开。选择电影可聚焦关联地点，选择地点可阅读场景记录；密集地区通过屏幕网格聚合保持可读。

A small, inspectable route model

小而可检查的路线模型

Stops are unique place IDs. Haversine distance measures the connection between stops. Dynamic programming finds the shortest open path through up to eight places while keeping the chosen first stop. It optimises straight-line distance, not travel time or accessible walking paths.

每站使用唯一地点 ID；站间采用 Haversine 距离。动态规划在最多八站内求最短开放路径，并保留首站。优化目标是直线距离，而非行程时间或可通行的步行路径。

Static by design

为静态部署设计

An explicit exporter copies only the movie, place and scene tables from SQLite to JSON. No user check-ins or route tables are published. HTML, CSS, JavaScript and public catalogue assets run on GitHub Pages; itineraries and personal place notes stay in browser storage. Notes support creation, editing, deletion, search, and JSON import/export. Basemap tiles require an internet connection.

导出脚本只将电影、地点与场景表从 SQLite 转为 JSON，不发布用户打卡或行程表。页面和目录资源由 GitHub Pages 提供，个人行程与地点笔记留在浏览器中；笔记支持新增、编辑、删除、搜索和 JSON 导入导出。底图需要联网加载。

What needs more work

下一步值得完善的地方

Verify film metadata and location evidence record by record; resolve unmapped and duplicate place records; check venue access and closures. Real walking-time optimisation, live opening hours and shared cloud itineraries remain future work. No user study or tourism-impact evaluation is claimed.

逐条核验电影元数据与取景证据，处理尚未定位和重复的地点记录，确认场所通行条件与关闭情况。真实步行时间优化、实时营业信息和云端共享行程仍属于后续工作。目前未开展用户研究或旅游影响评估。
